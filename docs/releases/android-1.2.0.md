## English

HRT Tracker can now check for new Android releases. In **Settings → About**, **App updates** shows your installed version and lets you **Check for updates**. You can also turn on **Automatically check for updates**. It's off by default. When enabled, the app can try once every 24 hours when you open it or return to it. Checks read the public GitHub release list. Your tracking records stay on your device.

With automatic checks enabled, the update notice offers **View release** and **Later**. **View release** opens the GitHub release page so you can download the APK when you're ready. **Later** hides the notice for that version, and you can still check manually.

To update from 1.1.0, open the signed APK and choose **Update**. Your saved records carry over. [Download the Android APK](https://github.com/SweetSophia/hrt-tracker-mobile/releases/download/android-v1.2.0/hrt-tracker-1.2.0.apk)

## 简体中文

HRT Tracker 现在可以检查 Android 版有没有更新了。打开「设置 → 关于」，在「应用更新」里可以看到当前版本，也能点「检查更新」。想让应用帮你留意新版本，可以打开「自动检查更新」。这个开关默认关闭。打开后，应用会在启动或切回前台时检查，每 24 小时最多自动检查一次。检查只读取 GitHub 上的公开发布信息，你的记录会留在手机里。

开启自动检查后，发现新版本时会有一条提醒。点「查看发布」会打开 GitHub 的发布页面，想更新时再下载并安装就好。点「稍后再说」可以收起这个版本的提醒，之后仍然可以手动检查。

从 1.1.0 升级，打开安装包后点「更新」就行，原来的记录会保留。[下载安卓安装包](https://github.com/SweetSophia/hrt-tracker-mobile/releases/download/android-v1.2.0/hrt-tracker-1.2.0.apk)
