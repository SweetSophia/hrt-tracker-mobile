- **小数输入。** 记用药或填化验结果时，输入 `1,5` 或 `1.5` 都会记成 `1.5`。如果写法有歧义，比如英文界面里的 `1,234`，会提示你改一下再保存。
- **小屏和大字号。** 在小屏手机上调大字号后，「记录」和「检查」的标题以及底部标签放不下时会换行。触屏上的添加、保存和取消按钮更容易点中，空间不够时会移到下一行。
- **德语界面。** 在「设置 → 常规设置 → 语言设置」里选「Deutsch」，日期和数字就会按德语习惯显示。完整备份也会记住你的语言选择。用药表单里的鼻喷、皮下注射和皮下埋植这三项，现在选哪种语言都能看到翻译。
- **桌面快捷方式。** 首次设置完成后，长按应用图标，点「新增用药」就能打开表单。如果应用还在运行，而且用药表单还开着，点快捷方式就能接着填。点「保存」才会记下来。这个功能需要 Android 7.1 或更新版本，手机桌面也要支持应用快捷方式。

在「方案试算」里再次确认已经设好的开始时间，现在会保留你原来选的时间。
